# Print a BASTION fit

Display the model priors, sampling settings, credible interval level,
and the first five rows of component estimates with their time values.

## Usage

``` r
# S3 method for class 'bastion_fit'
print(x, ...)
```

## Arguments

- x:

  A fitted object of class `bastion_fit`.

- ...:

  Additional arguments passed to printing the component preview.

## Value

The fitted object, invisibly.
